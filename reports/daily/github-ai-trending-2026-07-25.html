AI 深度洞察

Agent Skills 赛道爆发，多个超 20 万星框架霸榜，Claude 技能与金融大模型成为焦点。

🔥 热度指数：4/5
今日 AI 趋势列表中出现多个 18 万～26 万星的 Agent Skills 相关项目，品类集中且星数异常高涨，反映市场情绪偏热，存在一定炒作成分。

热点项目

  • affaan-m/ECC 与 obra/superpowers：两大 Agent Skills 框架分别以 23.3 万星和 26.1 万星霸榜，提出“技能即代码”的代理开发范式。
  • mattpocock/skills 与 ComposioHQ/awesome-claude-skills：个人工程师技能集与 Claude 技能精选集分别获 18.8 万星和 7 万星，将 Skills 分享推向新高度。
  • shiyu-coder/Kronos：聚焦金融市场的基础模型，获 3.3 万星，展示垂直领域 LLM 的巨大需求。
  • alibaba/open-code-review：阿里开源的混合架构代码审查工具，结合确定性管线与 LLM Agent，提供精确行级评论。
  • citrolabs/ego-lite：为 AI 代理设计的零成本浏览器自动化工具，可共享登录状态而无需干扰用户。

推荐建议

  • 立即上手 Agent Skills 开发：克隆 affaan-m/ECC 或 obra/superpowers，按照文档构建第一个自定义技能，体验代理自动化流程。
  • 将 AI 代码审查集成到你的流水线：在私有仓库中部署 alibaba/open-code-review，配置内置规则并接入 OpenAI 或 Anthropic 模型进行行级审查。
  • 构建个人 Claude 技能集：参看 ComposioHQ/awesome-claude-skills 和 mattpocock/skills，提取适合自己的工作流，用 Claude Code 等工具加载并调优。

AI 深度洞察

Agent Skills 生态爆发，垂直技能包扎堆；低资源 LLM 训练与本地 AI 基建走热。

🔥 热度指数：4/5
Agent Skills 类项目占据近半且 star 量异常，如 affaan-m/ECC 达 24.5 万，但多数是技能封装而非底层突破；安全/逆向/去审查等猎奇方向进一步推高热度，因此偏热。

热点项目

  • affaan-m/ECC：Agent 性能优化系统，以 24.5 万 stars 领跑，覆盖 skills/instincts/memory/security，是 Agent 工程化的重要参考。
  • K-Dense-AI/scientific-agent-skills：把 AI Agent 变成科学家的技能库，165 个验证技能 + 100+ 科学数据库，兼容主流 AI 编码客户端。
  • zhaoxuya520/reverse-skill：逆向/渗透/安全技能路由包，AI 自动路由 + 工具链自举 + 自进化知识库，支持 Claude Code/Cursor/Cline。
  • jingyaogong/minimind：2 小时从零训练 64M 参数 LLM，极大降低大模型训练门槛，适合教学和快速原型验证。
  • p-e-w/heretic：自动去除语言模型审查，引发 AI 安全与伦理讨论，是本次趋势中最具争议性的项目。

推荐建议

  • 采用 Agent Skills 标准：以 K-Dense-AI/scientific-agent-skills 为参考，把科学数据库/领域 API 封装成可复用技能包，接入 Claude Code/Cursor。
  • 用 affaan-m/ECC 的 skills/memory/security 模块优化现有 Agent 工作流，重点解决多技能包的上下文管理和安全边界。
  • 用 jingyaogong/minimind 在 2 小时内从零训练 64M 参数 LLM，跑通数据准备、预训练、指令微调，快速验证小模型落地。

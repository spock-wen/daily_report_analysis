AI 深度洞察

AI Agent 技能生态全面爆发：security-audit-skill、agent-skills 领跑，Agent 基础设施（沙箱、编排、桌面自动化）成新战场。

🔥 热度指数：4/5
addyosmani/agent-skills 单项目近 10 万星，Anthropic 生态（claude-code、knowledge-work-plugins）持续霸榜，Skills 类轻量项目易积累星数，存在一定热度溢价，但 Cloudflare/coder 等生产级基础设施也真实落地。

热点项目

  • addyosmani/agent-skills 达 96999 星，宣告'AI 编码 Agent 技能包'成为独立工程学科，生产级技能复用成主流范式
  • cloudflare/security-audit-skill（16253 星）将安全审计封装为 Agent 技能，输出可机器验证的审计结果，AI 安全审计工具化落地
  • anthropics/claude-code（146689 星）+ anthropics/knowledge-work-plugins（25114 星）双线布局，Anthropic 从编码 Agent 向知识工作者场景横向扩张
  • trycua/cua（24372 星）主打 Computer-Use 2.0 跨 OS 桌面自动化机群与评测基准，GUI Agent 进入可训练、可评估的基础设施阶段
  • cactus-compute/needle（11591 星）用 2-bit 8-29MB 超小模型实现端侧工具调用与结构化抽取，AI 下沉到手机/穿戴/微控制器等微型设备

推荐建议

  • 立即试用 addyosmani/agent-skills 和 cloudflare/security-audit-skill，将安全审计与工程最佳实践技能包接入自己的 Claude Code/Codex 工作流
  • 关注端侧 AI 方向：研究 cactus-compute/needle 的 2-bit 量化与工具调用方案，为 IoT/移动端产品评估本地推理落地可能
  • 若构建 Agent 平台，参考 coder/coder 的安全开发环境与 trycua/cua 的机群+基准设计，提前补齐沙箱隔离与评测能力

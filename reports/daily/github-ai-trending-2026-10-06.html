AI Agent 技能层（Skills）成为绝对风口，工程化 prompt 资产和 Agent 记忆管理主导今日趋势。

热点项目

  • mattpocock/skills（27.8 万星）：把 .agents 目录开放为'真实工程师技能库'，标志 Skills 成为可复用的工程 prompt 资产
  • msitarzewski/agency-agents（15.8 万星）：整套人格化 AI 代理团队（前端、社区运营等），Agent 编排从工具走向'虚拟团队'形态
  • thedotmack/claude-mem（9.7 万星）：跨会话持久记忆层，AI 压缩上下文并注入未来会话，兼容 Claude Code/Codex/Gemini 等多客户端，解决 Agent 短暂记忆痛点
  • cathrynlavery/diagram-design（4.4 万星）与 pbakaus/impeccable（7.8 万星）：'让 AI 产出更有设计感'的设计语言/规范类项目走红，AI 输出审美工程化成新赛道
  • earthtojake/text-to-cad（1.8 万星）与 morluto/rea（9.2 千星）：Agent 能力外溢到 CAD 建模和逆向工程等垂直硬核领域

推荐建议

  • 立即学习 Skills 生态：克隆 mattpocock/skills 和 msitarzewski/agency-agents，研究其 agent/skill 的 Markdown+Shell 结构，沉淀自己的团队级 prompt 资产
  • 为 Agent 工作流接入持久记忆：试用 thedotmack/claude-mem 跨会话上下文方案，并与 ayghri/i-have-adhd（5.4 万星，ADHD 友好输出）结合优化 Agent 响应可读性
  • 垂直方向布局：后端/系统开发者可关注 deepseek-ai/DeepGEMM（GPU BLAS 内核）补齐推理性能功底；安全研究者可试水 morluto/rea 的 Agent 驱动逆向工程，这两个领域 AI 化刚起步、竞争尚少

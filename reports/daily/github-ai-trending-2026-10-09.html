Agent Skills 成今日绝对主线，工程化 AI 工具链（逆向、代码审查、网关）集体爆发，Skills 生态正成为新的流量与标准之争。

  • mattpocock/skills（28.2 万星）：TypeScript 圈 KOL 开放个人 .agents 目录，'Skills for Real Engineers' 引爆 Agent Skills 生态，头部个人品牌效应显著

  • morluto/rea（4.5 万星）：用 Agent 从应用行为逆向到原生二进制，AI + 逆向工程结合的新范式，TypeScript 实现
  • alibaba/open-code-review（4.5 万星）：阿里开源的混合架构代码审查工具，确定性流水线 + LLM Agent，内置 NPE/XSS/SQL 注入多语言规则集
  • BerriAI/litellm（6 万星）：Rust 核心重写的轻量 AI 网关，统一 100+ LLM API 并支持成本追踪与负载均衡，成为企业接入层事实标准

推荐建议

  • 立即调研 Agent Skills 生态：阅读 mattpocock/skills 与 addyosmani/agent-skills，将高星 Skill 引入自己的 Claude Code/Codex 工作流，并考虑沉淀团队专属 Skill
  • 评估用 BerriAI/litellm 统一公司多模型调用入口，利用其 Rust 核心的性能优势做成本追踪与 guardrails；同时试用 alibaba/open-code-review 替换或增强现有 Code Review 流程
  • 关注 AI + 系统级工程交叉方向：morluto/rea（Agent 逆向）与 Robbyant/lingbot-map（流式 3D 重建，ECCV 2026 候选）代表新研究红利期，可提前跟进复现

  • anomalyco/opencode（21.5 万星）与 anthropics/claude-code（15.2 万星）并立：开源编码 Agent 与官方终端 Agent 双雄格局形成，生态竞争白热化
  • stablyai/orca（9.5 万星）：用自有订阅统一管理 Agent 舰队（桌面/移动/远程运行时），多 Agent 编排从概念走向生产工具
  • K-Dense-AI/scientific-agent-skills（5.2 万星）：177 个验证技能 + 100+ 科学数据库，'AI 科学家'赛道在生物/化学/药物发现领域落地
  • 基础设施两极分化：akitaonrails/ai-memory（Rust 长期记忆 + 跨厂商交接）与 xerj-org/xerj（Elasticsearch 兼容、省 40x token 的 Agent 搜索索引）解决 Agent 记忆与成本痛点

推荐建议

  • 立即试用 anthropics/claude-plugins-official（4.2 万星）官方插件目录，结合 affaan-m/ECC 优化现有 Claude Code 工作流的技能与记忆配置
  • 关注 akitaonrails/ai-memory 与 xerj-org/xerj 两个 Rust 项目：跨 Agent 记忆交接和低 token 数据索引是降低 Agent 运营成本的关键，适合早期介入贡献
  • 语音/科学垂直方向可评估 debpalash/VoiceStudio（本地化 646 语言语音克隆替代 ElevenLabs）与 K-Dense-AI/scientific-agent-skills（科研 Agent 技能标准），按领域选型接入

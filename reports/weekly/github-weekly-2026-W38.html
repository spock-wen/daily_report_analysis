Agent 技能包与上下文工程主导榜单，AI 输出质量控制（去 AI 味）成新热点
本周 21 个上榜项目中 AI 相关占 19 个（约 90%），围绕 Claude Code 等 Agent 生态的周边工具呈爆发态势：affaan-m/ECC 以 26.4 万星领跑，addyosmani/agent-skills（9.8 万星）连续三天上榜显示'Skills 市场'持续成型；同时 blader/humanizer（5.1 万星）、petergyang/no-ai-slop（1.1 万星）、ayghri/i-have-adhd（4.9 万星）三个项目聚焦 AI 写作痕迹消除与输出可读性，说明行业关注点从'能力增强'转向'质量与体验优化'。mksglu/context-mode（2.4 万星）与 worktrunk（8.2 千星）则反映上下文工程与并行 Agent 工作流成为工程刚需。
Agent 生态的'能力标准化'革命：Skills 成为 AI 编码的新包管理
AI Agent 的价值正从模型本身转移到以 SKILL.md、插件、MCP 为载体的标准化能力层，开源社区正在为 Agent 构建'技能包管理'生态。

本周 GitHub Trending 最深刻的信号，不是又一个大模型，而是 Agent 能力层的标准化*正在悄然成型。正如 Docker 之于部署、npm 之于 JS，'Skills' 正在成为 AI 编码 agent 的通用能力封装格式。云厂商和意见领袖率先入场：**cloudflare/security-audit-skill**（09-16）将多阶段安全审计封装为一个可验证的机器可读技能，**addyosmani/agent-skills**（09-15）提供了生产级工程技能集，**tech-leads-club/agent-skills**（09-13）则更进一步，试图建立一个'经过安全验证的技能注册表'——这本质上就是技能生态的 **npm registry**。社区项目迅速跟进：**SnailSploit/Claude-Red**（09-13）把攻击性安全方法论拆成结构化 SKILL.md，**Tencent/BrowserSkill**（09-17）让任意 shell 型 agent 拥有真实浏览器操控能力，**affaan-m/ECC**（09-17）甚至开始做 agent harness 的性能优化系统，包含'技能、本能、记忆'——这是典型的运行时包管理思维。配套基础设施也在同步涌现：**Fission-AI/OpenSpec**（09-18）提供规范驱动开发，**pacifio/atlas**（09-15）为多 agent 做源码版本控制，**yynxxxxx/Codex-X**（09-19）为 Codex 的 Skills/MCP 提供可视化管理界面。为什么现在发生？因为模型能力已趋于同质化，**竞争焦点从'哪个模型更强'转向'agent 拥有哪些可复用、可审计、可组合的能力'**。当 Anthropic 以 **anthropics/knowledge-work-plugins**（09-16）和 *anthropics/claude-code（09-16）亲自下场构建插件生态时，可以确认：Agent 领域的'包管理战争'已经打响，而 Skills 格式就是它的 manifest.json。

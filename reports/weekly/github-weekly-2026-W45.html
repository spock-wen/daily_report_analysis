核心叙事 ≤3 节

1. Skills 正成为 AI Agent 时代的新『操作系统接口』

工程经验正被封装为可移植的 Skills 层，让任意 agent 跨模型、跨工具复用人类工作流，形成新的软件接口标准。 过去一周 Trending 最深层的主线，是 **Skills 正在取代传统插件与 prompt 模板，成为 AI Agent 的『操作系统接口』**。 故事从需求侧开始：开发者发现单个 agent 能力有限，真正稀缺的是经过验证的**工作流知识**。mattpocock/skills 从 11月1日 起多日霸榜，直接把资深工程师的 `.agents` 目录开源，说明人们开始像当年 fork 框架一样 fork 工程方法论。随后 11月6日，生态巨头集体入场：google/skills 为 Google 产品发布官方 Agent Skills，scenario-labs/skills 把图像、视频、音频甚至 Blender、Unity 专业软件的调用封装成 skills，ConardLi/garden-skills 也贡献了中文社区版本。Skills 已经从个人技巧演化为**厂商竞逐的标准层**。 为什么此刻发生？因为 Agent 的瓶颈已从『模型能力』转移到『上下文与协调』。thedotmack/claude-mem 多日霸榜，解决跨会话记忆；max-sixty/worktrunk 连续多日上榜，用 Git worktree 支撑并行 agent 工作流；vercel-labs/agent-desktop 与 vercel-labs/agent-browser 则为 agent 提供统一的计算机与浏览器操作面——这些项目共同构成了 Skills 之下的**运行时底座**。而 garrytan/gstack（11月5日）把一位 CEO 的完整组织角色打包成 个工具，Donchitos/Claude-Code-Game-Studios 更是用 个 agent、 个技能复刻真实工作室层级，证明 Skills 组织化后可以模拟**整个组织结构**。 更深一层：连传统基础软件也嗅到了接口迁移。11月7日 rails/rails、react/react、

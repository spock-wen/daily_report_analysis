核心叙事 ≤3 节

1. Skills 生态爆发：Agent 从玩具走向生产力的知识化拐点

过去一周，围绕「技能包」的创建、分发、评估与合规工具集中涌现，标志 Agent 开发进入知识工程阶段。 回顾 2026-11-16 至 2026-11-22 的 Trending 榜单，最值得注意的是「Agent Skills」从零散的提示词技巧演变为一个完整的<b>知识工程生态</b>。榜单上同时出现了技能的<b>供给端</b>、<b>分发端</b>与<b>质检端</b>，这很少见。 供给端的项目都在把领域专家经验封装成可复用单元：elementalsouls/Claude-BugHunter 把数百份漏洞披露报告提炼成多类漏洞模式的技能包；tradermonty/claude-trading-skills 面向交易员；kajisho5/ffmpeg-skill 则把视频剪辑的命令行知识变成带机器可读契约的工具集。这些项目的共同痛点是：模型能力已经够强，缺的是<b>结构化领域知识</b>。 分发与标准化端，cursor/plugins 提供官方插件规范，google-labs-code/stitch-skills 明确遵循 Agent Skills 开放标准以兼容多家编码 Agent，obra/superpowers 直接给出整套方法论。生态一旦繁荣，质量问题随之而来——于是 NVIDIA/SkillEvaluator 在多日霸榜，用质量门与语义重叠检测解决技能包重复与劣化问题，这正是生态成熟的信号。 更深一层，合规类项目 mjmirza/app-store-compliance 把平台审核规则也做成技能供 Agent 使用，说明<b>制度知识本身正在被技能化</b>。背后的因果链清晰：Agent 编排层（如 Tencent/LoopForge）成熟后，人类反馈回路（如 backnotprop/plannotator）不再稀缺，真正制约 Agent 产出质量的是知识供给，本周榜单正是这一瓶颈被产业集体意识到的时刻。

2. GoogleChrome/modern-web-guidance-src

解决代理生成代码依赖过时 Web 实践的问题。

3. AI 原生办公

把文档、表格、演示的编辑与协作能力同时开放给人与 AI 代理，办公软件正在被重新定义。
